# Bundled fonts

Used by the client "Due Diligence Dossier" PDF (QuestPDF) and, from Phase 7 Track B, the portal UI.
All three families are licensed under the **SIL Open Font License 1.1** (redistribution permitted).

| File(s) | Family | Source | Notes |
|---|---|---|---|
| `Fraunces-{Regular,Medium,SemiBold}.ttf` | Fraunces | github.com/google/fonts `ofl/fraunces` | Static instances of the variable font (`wght` 400/500/600, `opsz` set for display, `SOFT`/`WONK` 0), produced with `fonttools varLib.instancer`. |
| `IBMPlexSans-{Regular,Medium,SemiBold}.ttf` | IBM Plex Sans | github.com/IBM/plex `v6.4.2` | As shipped. |
| `IBMPlexMono-{Regular,Medium}.ttf` | IBM Plex Mono | github.com/IBM/plex `v6.4.2` | Identifiers, ₹ amounts, dates. |
